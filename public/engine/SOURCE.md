# Stockfish.js browser engine

The two engine assets in this directory are the unmodified `lite-single` files from [Stockfish.js v19.0.1](https://github.com/nmrugg/stockfish.js/releases/tag/v19.0.1). Stockfish.js and its underlying Stockfish engine are GPL-3.0 licensed; see [COPYING-GPL-3.0.txt](COPYING-GPL-3.0.txt). The corresponding source and build instructions for this exact release are at <https://github.com/nmrugg/stockfish.js/tree/v19.0.1>.
